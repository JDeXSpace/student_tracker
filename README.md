# Student Tracker 📊

**Student Tracker** est un outil automatisé d'analyse de clustering et de reporting pédagogique, conçu pour analyser les parcours et les performances des étudiants au sein d'une promotion.

## 🎯 Objectifs du Projet

* **Analyse de Clustering (K-Medoids)** : Segmentation déterministe des étudiants en groupes homogènes, calcul des métriques de performance et analyse de la distance entre les prototypes.
* **Anonymisation et Sécurité des Données** : Dissociation stricte entre les rapports publics (où les données personnelles / PII sont masquées) et les fichiers d'audit locaux gardés strictement hors de Git.
* **Reporting Visuel Automatisé** : Génération de graphiques et de rapports HTML/PNG structurés pour chaque cluster.
* **Publication Web** : Hébergement dynamique et public des tableaux de bord via **GitHub Pages**[cite: 5].

# Student Tracker 📊

**Student Tracker** is an automated cluster analysis and pedagogical reporting tool designed to analyze student pathways and performance within a cohort.

## 🎯 Project Objectives

* **Cluster Analysis (K-Medoids)**: Deterministic segmentation of students into homogeneous groups, calculation of performance metrics, and analysis of prototype distances.
* **Data Anonymization and Security**: Strict separation between public reports (where personal data / PII is masked) and local audit files kept strictly out of Git.
* **Automated Visual Reporting**: Generation of structured HTML/PNG reports and charts for each cluster.
* **Web Publication**: Dynamic and public hosting of dashboards via **GitHub Pages**[cite: 5].
